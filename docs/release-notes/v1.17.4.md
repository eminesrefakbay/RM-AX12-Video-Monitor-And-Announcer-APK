# AX-HUD 1.17.4

## Changed

* **The SDK notice is updated.** The SDK developer answered in the issue on the SDK repository: "we do not impose any restrictions on the use or redistribution of the sdk." This is a statement in a public issue, not a licence text. The README, the About page and the third-party notices say so.
* **The 12 second start-up delay.** The SDK developer confirmed that it is a design consequence of the automatic serial-port discovery, and that an API taking the port and baud rate, for example `initialize(dataFolder, portName, baudRate)`, will be considered in a future SDK. The app cannot shorten it until then.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

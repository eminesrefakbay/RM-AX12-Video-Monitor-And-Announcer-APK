# AX-HUD 1.17.5

## Changed

* **The return reserve card no longer blocks the OSD.** Settings > Aircraft > Return reserve has new rows: size (small, medium, large), position (top centre, left, right), opacity (50, 75, 100 %) and hide after (never, 5, 10, 30 seconds). By default the card is smaller and goes away after 10 seconds. It comes back when the reserve changes state (low, then gone), and the spoken warnings are unchanged.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

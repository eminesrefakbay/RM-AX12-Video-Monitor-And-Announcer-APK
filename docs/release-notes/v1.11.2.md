# AX-HUD 1.11.2

## Fixed

* **The antenna tracker's declination dialog** named one town and gave a value for it. It now reads "Magnetic declination (degrees, east is
  positive)" in all four languages. Look up the value for your own location.
* **The tracker firmware's default declination** was 5.5 degrees east (a value for one town); it is now 0 until the app sets it. If you
  flashed the tracker before, set the declination again in *Settings > Antenna tracker*; the stored value is kept.
* The tracker README no longer names a place.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

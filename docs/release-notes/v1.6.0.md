# AX-HUD 1.6.0

A new voice for the app.

## New

* **Fonts.** Manrope for menus, settings and all running text; **Teko**, a narrow techno face, for page titles and the big numbers of the
  dashboard cards. Both are open fonts (SIL OFL 1.1), bundled in the app (222 KB for six files) and credited in About.
* **Digit slots.** Teko has no fixed-width digits, so every number of the cards is drawn digit by digit in slots of the same width: a speed
  or a time no longer shifts sideways while it counts.
* **A typography scale.** Card titles are in capitals (a Turkish i becomes İ), letter-spaced and medium; headings semi-bold; labels medium;
  body regular. The statistics, charts, compass, sticks, value cards and every panel, dialog and list follow it.
* If the font files cannot be loaded, the system fonts stay (and the diagnostics say so). Chinese keeps using the radio's own font.

German, Turkish and Chinese texts for the two credits are included (machine-assisted).

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

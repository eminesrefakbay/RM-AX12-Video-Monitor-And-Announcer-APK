# AX-HUD 1.10.2

## Fixed

- **The first screenshot no longer pauses the radio link.** Android asks for storage access the first time (on the AX12's Android 9); the
  dialog pauses the app, which let go of the radio link and needed about 12 seconds to come back. The app now holds the link, as it does for
  the camera permission, and does not ask while the aircraft is armed (it says to do it on the ground).
- The horizon card removes its expiry timer when it leaves the screen.

## Documentation

- The README no longer says that nothing has rounded corners, that Chinese is skipped on radios without a Chinese font, or that the
  splash is a still logo for two seconds. The serial-lock section names the real files, `ax-hud.apk` and `ax-hud-plain.apk`, in all four
  READMEs. The Settings label of the splash says "animated, about 3 seconds".
- New tests check that the README, the CI file names and the release notes agree.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

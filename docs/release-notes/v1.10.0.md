# AX-HUD 1.10.0

## Dashboard

- Save, load, replace and delete up to 10 named dashboard layouts.
- Start from the Full flight, Minimal flight or Channel bench preset.
- Include saved layouts in settings backup and restore.
- Dashboard layout controls are available in English, Turkish, German and Simplified Chinese.

## Responsiveness

- Move radio polling and CRSF parsing off the UI thread while preserving ordered processing for rules, statistics and flight logs.
- Avoid unnecessary redraws in the horizon, compass and radar cards.

# AX-HUD 1.12.1

## Fixed

* **Signal strength (RSSI) was wrong.** The AX12's module sends the signed byte, and the app read it as a magnitude, so -55 dBm showed as
  -201 (in the HUD, the cards and the logs). It now reads both forms. In your old logs the true value is the absolute value minus 256.
* **The log rate.** The radio is polled 20 times a second, so "25 rows per second" really gave 20. The rate setting now goes up to 20, and the
  last line of every log has `actual_rate_hz`, the rate the flight really got. The log header says that values from the aircraft change only
  when the link sends them.
* **`win_left`** is now negative once the approval window has ended (minutes over), and empty only before it opens or when it is off.
* **Descriptions.** `dbm` is the radio's own signal figure (a small positive number, not dBm), `lost` is a heartbeat (0 means the receiver is
  lost, 5 means alive), `tx_power` changes with dynamic power. They are said so in the variable lists, in four languages.

## New

* The README section "Reading a flight log" explains the rows, how fresh each value is (about once a second at an ELRS telemetry ratio of 1:32),
  the signal columns, `win_left`, and what `OK` and `!ERR` mean in the flight-mode column. Settings > Flight logs has a short note about it.

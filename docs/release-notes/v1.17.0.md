# AX-HUD 1.17.0

## New

* **Hills under the 3D replay.** The map in the replay lies on a rough 3D shape of the real land, with no contour lines and no labels. Settings > Display > Hills in 3D: Off, Real size, Twice as high, Three times as high.
* The aircraft, its shadow line, the drop lines, the flags and the HOME ring stand on the ground, and the camera stays above it.
* The credit line names the elevation data (USGS SRTM, GMTED2010, Copernicus EU-DEM, via AWS Terrain Tiles).

## Notes

* The heights are for looking and not exact. The flight ribbon keeps the logged heights, so it can show through a hill (there is no depth buffer).
* The elevation tiles come from AWS Terrain Tiles on Amazon S3: a few small files per flight, kept on the radio. That server sees your IP address and the area. Its documentation says the bucket is meant for use from AWS cloud machines, so check its terms. Set Hills in 3D to Off to stop the requests. Without the data the ground stays flat.

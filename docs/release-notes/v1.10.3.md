# AX-HUD 1.10.3

## Fixed

- **Screenshots work again on the AX12.** The radio's Android 9 lists the storage permission as two switches, "modify or delete the contents
  of your SD card" and "read the contents of your SD card". The app asked for the first only, and saving to `Pictures/AX-HUD` failed until
  the second was switched on by hand. The app now declares both, asks for both in one dialog, and keeps the radio link while the dialog is open.
- The folder check uses `isDirectory` instead of `exists`, which can report a folder as missing when the read permission is off.
- A failed screenshot is written to *Settings > Diagnostics* (the events), so that the reason can be seen and sent in a bug report.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

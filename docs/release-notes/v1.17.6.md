# AX-HUD 1.17.6

## Added

* **Choose the radio's serial port and baud rate.** Settings > System > Radio serial link: `ttyS0 921600` (default), `ttyS0 1870000` (ELRS 1000 Hz and all packet rates), `ttyS0 400000`, or Automatic (the SDK scans, as before). The new SDK opens a named port at once, which should remove most of the roughly 12 second wait at start. The baud rate has to match the radio. A change applies the next time you start the app.

## Changed

* **New SDK version.** The build now uses RadioMaster's SDK from `flyshark2024/rmAxSdk` (27 Nov 2026), which has the port and baud rate in `initialize()`.
* **The SDK licence.** RadioMaster added a licence file to the SDK (use, copy, distribute and redistribute the binaries and headers, commercial or not). The README, the third-party notices and the About page now say so, and the About page shows the licence text.

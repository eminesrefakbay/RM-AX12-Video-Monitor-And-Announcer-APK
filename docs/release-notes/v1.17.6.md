# AX-HUD 1.17.6

## Added

* **Choose the radio's serial port and baud rate (experimental).** Settings > System > Radio serial link: Automatic (default, the SDK scans for the port as before), or `ttyS0` at 921600 (the radio's own link rate). In the first test the named port opened at once, but the radio configuration did not load, so keep Automatic until RadioMaster confirms how the new `initialize()` is meant to be used. A change applies the next time you start the app.

## Changed

* **New SDK version.** The build now uses RadioMaster's SDK from `flyshark2024/rmAxSdk` (27 Nov 2026), which has the port and baud rate in `initialize()`.
* **The SDK licence.** RadioMaster added a licence file to the SDK (use, copy, distribute and redistribute the binaries and headers, commercial or not). The README, the third-party notices and the About page now say so, and the About page shows the licence text.

AX-HUD is an independent project and is not affiliated with or endorsed by RadioMaster.

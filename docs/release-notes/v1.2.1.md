# AX-HUD 1.2.1

A tidier layout editor.

## Changed

* The explanatory text and the wide bar over the top of the screen are gone. The editor now has a small see-through strip of icon buttons
  at the top centre: **+** add a card, **-** remove a card, a **pencil** to edit a value card (dashboard), a **grid** button, a
  **reverse arrow** to reset the layout and a **tick** when you are done.
* **Snap to grid**: a grid is drawn while you edit, and a card's corner and its size snap to 16 dp cells. It is on by default, the grid
  button switches it off and on, and the screen edges still win when a card is close to them. The choice is part of the settings backup.
* Works the same on the video page and on the dashboard.
